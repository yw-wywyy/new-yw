## 8.6 Git 基础操作
- 完成了git图形化操作，体验构建仓库，体验修改、分支和回退等一系列操作
- git操作顺序:
  1. init
  2. add
  3. commit
  4. branch
  5. merge
  6. push
- 表格
  | 命令 | 作用 | 什么时候用 |
  |-----|-----|-----|
  |git init|仓库初始化|新建一个项目|
  |git commit -m "提交名"|提交|保存更改|
  |git push|推送到远程|本地提交后，推送到远程仓库|
